# 欢迎来到我的网站

这是一篇示例文章，用来展示 Markdown 的写法。Markdown 是一种轻量级的标记语言，用简单的符号就能写出结构清晰的文档。

## 为什么用 Markdown

- 纯文本，方便查看和修改
- 语法简单，容易上手
- 天然适合写博客和技术文档
